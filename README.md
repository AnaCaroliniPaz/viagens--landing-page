# 🌍 Viagens — Landing Page

Uma landing page moderna e responsiva inspirada em um vilarejo europeu.  
Este projeto foi desenvolvido para praticar HTML5, CSS3 e o uso de navegação interna com links âncora.

---

## ✨ Funcionalidades

✔️ Banner com imagem de vilarejo europeu  
✔️ Texto sobreposto ao banner  
✔️ Menu de navegação interno  
✔️ Botão “Voltar ao topo”  
✔️ Seções:
- 🧳 Minha Viagem  
- 📍 Nos Encontre  
- 💡 Conselhos  
- 📬 Contate-nos  

✔️ Layout responsivo  
✔️ Conteúdo em **Português (pt-BR)**  
✔️ Uso de tags semânticas (`header`, `nav`, `main`, `section`, `footer`)

---

## 🖥 Tecnologias Utilizadas

- HTML5  
- CSS3  
- Git & GitHub  

> Não foi utilizado JavaScript obrigatoriamente.
